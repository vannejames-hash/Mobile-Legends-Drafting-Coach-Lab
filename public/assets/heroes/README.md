# Hero portraits

One square portrait per hero, named by hero **id** (not display name), WebP preferred:

    public/assets/heroes/<heroId>.webp

Served at `/assets/heroes/<heroId>.webp`. Any image that is missing falls back to a role placeholder automatically.
To use a different file or URL for one hero, add it to `data/hero-portraits.json` → `overrides`.
Check coverage with `node tools/check-portraits.js`.

Recommended: square, at least 256×256, face in the upper-middle of the frame.
